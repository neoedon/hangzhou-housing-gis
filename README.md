# 杭州住房与入学 GIS · For 一一

公开入口：[打开 GitHub Pages GIS](https://neoedon.github.io/hangzhou-housing-gis/)。本地入口：[http://127.0.0.1:8766/](http://127.0.0.1:8766/)。这是独立的只读 GIS 应用，旧版地图、原始报告和各任务的自动化均保留。

Pages 发布包由已验证的 SQLite 索引生成，但不会上传 SQLite、原始抓取目录、本机路径或隔离记录。公开版通过静态分片按需读取地点详情；地图筛选、学校—小区跳转、价格、新房、原帖搜索、时间快照和来源归档保持可用。

## 已能使用

- 从小学/校区进入，按招生年度与类型查看官方名单；学校、小区/招生地址、原帖、价格档案双向跳转，返回保留查询和视口。
- 地区、小学/小区、本地关键词、候选、收藏、点位状态、预算、面积、年代和成交日期筛选。学校模式下，房屋条件沿所选年度的名单关系筛选学校。
- 当前视野查询、两次点击对角的矩形圈选、名称标识只显、点位只显。地图和左侧结果使用同一查询；选中、关联和比较点作为明确标记的例外保留。
- 官方年度名单、同帖提及、2 公里附近参考分开切换。所有地图图层统一到一个 MapLibre 相机和画布，未使用双地图叠加。
- 比较 2—4 个小区，地图显示相同编号；本机收藏、手动资金差额草稿；不自动导入家庭身份/资产，不写入可分享地址或发给底图服务。
- 60 个候选日快照；只回放该期候选观察字段，不冒充整库时光机。观察折线不包含所选快照之后的数据；招生年度和成交日期独立选期。
- 原帖搜索覆盖全部 3,052 条索引，其中 571 条含正文/说明；先做全量匹配和空间过滤，再分批显示卡片，未定位原帖不伪造落点。

### 决策边界

滨江、拱墅学校目录和关系数据统计截至 **2026-05**，于 9 月 8 日重新读取；官方空预警不是低风险，没有 2029 入学保证。学校服务区仅展示官方文本，不能用行政区、半径或附近小区生成猜测学区。官方学校编号与地图旧名/校区拆分时，先使用门户校点转换后的空间近邻桥接；彩虹城小学另保留公开校区沿革证据。直接名单没有命中时，系统依次展示同帖、2 公里附近或同区官方资料核验入口，不再出现无关联空面板；这些补充入口均标明“不是对口结论”。

此版适合本地研究、筛选和证据导航；不等于全部项目内容已完成实体核验，也不能直接作为入学资格、购房或融资结论。仍需优先补核两区的名称别名、校区/分期、缺失点位和更新的成交/在售依据。

界面正文、控件、图例、地图业务标签和在线底图文字在运行时统一限制为最小 12px。

## 公开部署、本地启动与更新

生成 GitHub Pages 静态包：

```sh
python3 export_pages.py
```

输出位于 `docs/`。它包含 128 个地点详情分片及浏览器所需的只读 JSON，不包含 `data/housing.sqlite`。发布前应运行测试、核对 `docs/data/manifest.json`，并确认公开数据边界。

本地运行地址：[http://127.0.0.1:8766/](http://127.0.0.1:8766/)，只绑定本机。

下次使用可双击 `启动杭州GIS.command`，或在本目录运行：

```sh
python3 server.py --port 8766
```

浏览器无法连接时，先确认本地服务仍在运行。若提示端口已占用，不要结束未知进程；先检查该地址是否已是本 GIS。关闭运行服务的终端会停止服务。

更新完成的项目产物后，双击 `更新GIS数据.command`，或：

```sh
python3 build_data.py
```

更新只读取源文件，校验通过后原子替换 SQLite。源不完整、发生并发变动或验证失败时不覆盖上一份数据库。重新构建后需要刷新浏览器；接口会拒绝混用旧页面和新索引的版本。

本版适配器：自动选择完整候选日快照和学校最新有效索引；价格使用已核对的 6 月成交基线及当前公开挂牌 overlay。没有新增采集或改变原自动化调度。若以后更换成交基线文件、政策年度/字段结构，需要相应更新适配器并复核口径，不会把日报日期当作最新成交日期。

Python 主应用仅使用标准库。MapLibre 5.24.0 沿用项目已缓存文件，构建时校验 JS 哈希；矢量底图/字体来自 OpenFreeMap，需要网络。可以关闭在线底图继续使用本地点位与目录；并非完整离线地图包。

## 验证与维护

```sh
python3 verify.py
```

执行数据/API 与纯前端状态测试，并核对源文件、笔记本和浏览器回执。笔记本可用以下命令重跑（QA 可选依赖，不是应用运行依赖）：

```sh
uv run --with nbformat --with nbclient --with ipykernel python create_validation_notebook.py
```

- `qa/data_validation.ipynb`：已执行的数据口径、匹配覆盖、年份、原文件哈希验证。
- `qa/pointer-drag-audit.json`：真实浏览器按住鼠标移动，48 个渲染帧样本；学校点与相同位置底图建筑均命中。
- `qa/browser-functional.json`、`qa/browser-final-interactions.json`、`qa/responsive-layout.json`：真实浏览器交互和尺寸检查。
- `qa/validation_receipt.json`、`qa/VALIDATION.md`：最终验收与限制。

整页截图接口两种调用均超时。`qa/map-school-links.png` 是真实地图画布导出，不含侧栏，不冒充整页截图或完整像素验收。

## 文件职责

`build_data.py`：来源适配、实体与关系索引、源文件保护、原子构建。

`server.py`：静态资源白名单、只读参数化查询、同源/Host 约束、索引版本检查。

`web/model.js`：纯查询、关系、空间和草稿计算；`web/app.js`：地图与交互；`web/app.css`：布局。

`data/build_receipt.json`：构建日期、真实源日期、计数、输入文件指纹。原数据不在此应用内覆盖或移动。
